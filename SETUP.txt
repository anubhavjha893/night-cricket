INSTALL
Use Node 22.12+ and run npm install from the night-cricket root.
This installs both workspaces. npm shares node_modules, while dependency
ownership stays separate in frontend/package.json and backend/package.json.

ENVIRONMENT
Existing credentials have been preserved in backend/.env.
For a fresh checkout, copy backend/.env.example to backend/.env and set:
MONGODB_URI, JWT_SECRET (32+ random characters), ADMIN_EMAIL and
ADMIN_PASSWORD (12+ characters).
Copy frontend/.env.example to frontend/.env if you need a custom VITE_API_URL.
Frontend values are public: never put database/admin secrets there.
No root .env file is needed.

RUN FROM THE PROJECT ROOT
npm run dev:database     Start local MongoDB if it is not already running.
npm run dev              Start Express and Vite together.
npm run dev:frontend     Start only Vite (http://localhost:5173).
npm run dev:backend      Start only Express (http://localhost:4000).
npm run build            Build frontend and prepare the Sites artifact.
npm start                Serve frontend/dist and API from Express on port 4000.

RUN APPS SEPARATELY
In frontend/: npm run dev
In backend/: npm run dev
Build frontend before using npm start to serve the full app.
The optional local database helper downloads an official MongoDB binary on first
run. Data stays in project-root .data/mongo, regardless of the launch directory.

ADMIN
Open http://localhost:4000/#/admin (or Vite's /#/admin in development).
Use ADMIN_EMAIL and ADMIN_PASSWORD from backend/.env.
First server start creates an admin only if that email does not exist.
Changing environment credentials does not overwrite an existing admin password.

STORAGE
Records and images are stored in MongoDB; images use GridFS.
Private images require a player-owner or administrator session.
Uploads accept verified JPEG/PNG/WebP images up to 5 MB each.
Passwords are hashed and sessions use HttpOnly signed cookies.
Keep production MongoDB private and configure backups.

DOCKER
Create backend/.env, then run docker compose up --build from the root.
Open http://localhost:4000. Data stays in the tournament-data Docker volume.
Compose is for local HTTP. Public deployment needs HTTPS, NODE_ENV=production,
the exact APP_ORIGIN and an appropriate TRUST_PROXY setting.

DEPLOYMENT
Deploy the root Dockerfile or root npm build/start commands to a Node-capable host.
Provide production environment variables and a persistent MongoDB connection.
Express serves the frontend build and API on the same origin by default.
For separate hosting set frontend/.env VITE_API_URL before building and set
backend APP_ORIGIN to the exact frontend origin. Cross-site cookies require
production HTTPS and COOKIE_SAME_SITE=none, subject to browser restrictions.
The Sites host serves only the static React preview, not Express/MongoDB.
Root dist/ is a generated copy because Sites requires its artifact there.
